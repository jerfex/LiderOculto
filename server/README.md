# Server (Express + Socket.IO + Prisma)

## Setup
1. Copie `.env.example` para `.env` e ajuste.
2. Instale dependências e gere o cliente Prisma.
3. Rode as migrações e inicie o dev server.

## Scripts
- dev: ts-node-dev com reload
- build/start: compila para dist
- prisma:migrate: cria/atualiza schema no Postgres
